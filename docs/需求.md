# 教學小遊戲（翻牌配對、大小排序、連連看）— 需求（2026-10 起，2026-11 整合）

## 用途與對象
教學用。老師自訂內容，學生玩。主要在一般電腦用滑鼠，之後可能用平板（觸控）。

## 形態
純前端網站（靜態檔案）。資料留在使用者自己的瀏覽器。單機版暫不做。

## 配對內容（題庫）
一個「題庫」＝名稱＋多組配對。每一組配對由使用者自己編輯，兩張牌各自可以是圖片或文字，因此支援：

| 類型 | 例子 |
| :--- | :--- |
| 圖片配圖片 | 一般翻牌（兩張相同或相關的圖） |
| 圖片配文字 | 單字卡、詞彙（圖 ↔ 名稱） |
| 文字配文字 | 題目 ↔ 答案 |

- 同一個題庫可混用不同類型。
- 題庫可新增、改名、複製、刪除，並匯出成檔案分享、匯入。
- 圖片上傳後自動縮圖再存。

## 遊戲
- 難度：4×4（16 張＝8 組）、6×6（36 張＝18 組）、**自選牌數**（組數由使用者決定，不超過題庫的配對數）。
- 題庫配對數多於這局需要的組數時，隨機抽選。
- 翻牌動畫；配對成功／失敗／過關有音效（可關閉）。
- 計**步數**（每翻兩張算一步）與**計時**。
- **多人輪流**：2 人以上；每人可輸入名字；配對成功者再翻一次（可設定關閉）；顯示輪到誰、各人配對數；結束時顯示排名（同分並列）。
- **最佳紀錄**：單人局依「題庫＋牌數」分別記錄最少步數與最短時間；存在本機。

## 非功能
- 繁體中文介面；大按鈕、高對比；滑鼠與觸控皆可。
- 不需要網路與帳號；無第三方套件。
- 圖片與題庫不離開使用者的瀏覽器（匯出檔由使用者自行分享）。

## 已決定
- 多人「連續配對可再翻」預設開啟，可關。
- 內建範例題庫（動物圖配字、算式配答案）。
- 網站為多檔 ES module：雙擊 `index.html` 無法開啟，需本機靜態伺服器或 GitHub Pages。

- 記憶時間模式：開局全部亮出 3／5／10 秒（可關），期間不能翻牌，紀錄與一般模式分開計算。
- 多個題目共用同一個答案：不改資料格式，各建一組配對、答案填一樣；牌面相同的答案牌可互換，判定時依牌面而非配對編號。
- 單機版：打包成單一 HTML 檔（`node scripts/build-standalone.js`），雙擊即可使用；暫不做 .exe／.app。

## 整合（2026-11）：三個遊戲、一份題庫
原本的兩個專案（翻牌配對 memory-match、大小排序／連連看 order-line）合併為一個，放在 order-line 倉庫（網址 https://patalim.github.io/order-line/），memory-match 的 commit 歷史已併入。

### 大小排序
- 從有數值的配對抽 2～12 張，學生拖曳排序，按「揭曉答案」；排序時隱藏數值，揭曉後顯示並標示對錯，答錯時顯示正確順序。
- 方向：由小到大／由大到小。數值相同（並列）任何順序都算對。
- 拖曳用 Pointer Events 自己實作（滑鼠、觸控），也支援方向鍵；不用第三方套件。

### 連連看
- 左邊是卡片、右邊是打亂的數值（2～10 組），一對一。先點左邊再點右邊連線；點已連線的項目可拆線重連。
- 「顯示正確答案」：答對綠色實線、答錯紅色、補綠色虛線指出正確答案。
- 「核對答案（不顯示答案）」：答對的線變綠色並鎖定，答錯的線變紅色但不顯示答案；下一位玩家一開始操作，紅線自動清除，接著連剩下的（接力）。
- 數值相同（並列）連到任一個都算對。

### 計分
- 大小排序與連連看共用一份累計得分（答對數／總數）與回合數；只在這次開啟期間有效，不存檔。計時各自獨立。

### 共用題庫
- 一份題庫、三個遊戲。配對 = 兩面（a、b，各為文字或圖片）＋選填的數值、單位、說明文字。
- 排序與連連看只用有數值的配對；翻牌配對的第二張牌可選「自動」（由數值＋單位產生），所以「水果 ↔ 含糖量」不用另外建檔。
- 匯入：本遊戲的 JSON（單一題庫、整個題庫庫）、舊版 order-line JSON、CSV（可含「主題」欄一次建立多個題庫）、Excel（需網路載入讀取元件，沒網路退回 CSV）。匯出：單一題庫、全部題庫、CSV 範本。
- 舊版 order-line 存在 localStorage 的主題，第一次啟動時自動轉成題庫存進 IndexedDB；舊資料不刪除。
